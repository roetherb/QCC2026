# QCC 2026 Supporter Badge Cover v1.14 — Three-part outlined inlay

## Layer plan and printing

Print **flat exterior down, cavity up**, as supplied. At a 0.24-mm initial
layer and 0.24-mm subsequent layers:

| Layers | Z range | Materials |
|---|---|---|
| 1–2 | 0.00–0.48 mm | Body background, Artwork_Inlay and Artwork_Outline |
| 3–6 | 0.48–1.44 mm | Body only through the backplate |
| 7 onward | Above 1.44 mm | Body only for the remaining structure |

2 wall loops, **3 bottom and 3 top shell layers**,
and 15% Gyroid for regions where sparse infill exists. Use top/bottom minimum
shell thickness 0.72 mm or layer-count control. The broad backplate
is intended to be six solid layers with no intervening sparse layer.

For Bambu printers, suggested additional setting: **Quality → Wall generator → Arachne**.
